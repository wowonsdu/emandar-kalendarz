
# Emandar Kalendarz

React application for the public Emandar calendar, trainer directory, community events, and operational panel. Runtime state is served by the Fastify API and PostgreSQL-backed store; `seed-data/seed-store.json` is only a bootstrap/reseed source.

## Local development

1. Run `npm i`.
2. Run `pnpm dev` to start the web app and API.

## Verification

- `npm test`
- `npm run build`
- `npm run release:check`
