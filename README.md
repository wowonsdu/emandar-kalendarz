
# Emandar Kalendarz

React application for the public Emandar calendar, trainer directory, community events, and operational panel. On the `feature/prototyping` branch it runs on a shared mock backend backed by JSON files.

## Local development

1. Run `npm i`.
2. Run `npm run dev` to start the app with the built-in mock JSON API.

## Verification

- `npm test`
- `npm run build`
- `npm run release:check`
